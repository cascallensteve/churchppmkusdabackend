

## Authentication

All donation endpoints require **admin authentication**. Include the JWT access token in the request header:

```
Authorization: Bearer <access_token>
```

Only users with `is_staff=True` can access these endpoints.

### Create Donation Type

#### `POST /api/donation/donation-types/`

Create a new donation type.

**Request:**

```json
{
  "name": "Tithes",
  "description": "Regular tithe contributions (10% of income)"
}
```

**Success Response (201 Created):**

```json
{
  "id": 1,
  "name": "Tithes",
  "description": "Regular tithe contributions (10% of income)",
  "created_by": 1,
  "created_by_email": "cascallensteve@gmail.com",
```

## Data Model

### DonationType

| Field | Type | Description |
|-------|------|-------------|
| `id` | Integer | Primary key |
| `name` | String (255) | Name of the donation type |
| `description` | Text | Profile pitch / description (optional) |
| `created_by` | ForeignKey | Admin user who created the type |
| `created_at` | DateTime | Timestamp of creation |

## Admin Panel

Donation types can also be managed via the Django admin panel:

```
/admin/
```

- **List view** displays: Name, Created By (email), Created At
- **Search** by name and description
- **Filter** by creation date
