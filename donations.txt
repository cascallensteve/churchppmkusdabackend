

## Authentication

All donation endpoints require **admin authentication** unless specified otherwise. Include the JWT access token in the request header:

```
Authorization: Bearer <access_token>
```

Only users with `is_staff=True` can access admin endpoints.

## Data Model

### DonationType

| Field | Type | Description |
|-------|------|-------------|
| `id` | Integer | Primary key |
| `name` | String (255) | Name of the donation type |
| `description` | Text | Profile pitch / description (optional) |
| `created_by` | ForeignKey | Admin user who created the type |
| `created_at` | DateTime | Timestamp of creation |

## M-Pesa Payments

M-Pesa Daraja integration for processing donations via STK Push.

### Environment Variables

```bash
MPESA_CONSUMER_KEY=your_consumer_key
MPESA_CONSUMER_SECRET=your_consumer_secret
MPESA_SHORTCODE=174379
MPESA_PASSKEY=your_passkey
MPESA_ENVIRONMENT=sandbox
MPESA_CALLBACK_URL=https://your-domain.com/api/payments/callback/
```

### Payment Flow

1. Frontend fetches public donation types from `GET /api/donation/public/`
2. User selects donation type and enters phone number + amount
3. Frontend calls `POST /api/payments/initiate/`
4. M-Pesa sends validation request to `POST /api/payments/validation/`
5. M-Pesa sends confirmation to `POST /api/payments/callback/`
6. Frontend polls `GET /api/payments/status/?checkout_request_id=...` for status

### Initiate Payment

#### `POST /api/payments/initiate/`

Start M-Pesa STK Push payment.

**Request:**

```json
{
  "donation_type_id": 1,
  "phone_number": "254700000000",
  "amount": 100
}
```

**Success Response (200 OK):**

```json
{
  "message": "Payment initiated successfully. Please check your phone.",
  "checkout_request_id": "ws_CO_123456789",
  "transaction": {
    "id": 1,
    "donation_type": 1,
    "donation_type_name": "Tithes",
    "phone_number": "254700000000",
    "amount": "100.00",
    "status": "PENDING",
    "created_at": "2026-08-24T13:00:00Z"
  }
}
```

### Check Payment Status

#### `GET /api/payments/status/?checkout_request_id=...`

Check the status of a payment.

**Success Response (200 OK):**

```json
{
  "id": 1,
  "donation_type": 1,
  "phone_number": "254700000000",
  "amount": "100.00",
  "status": "SUCCESS",
  "mpesa_receipt": "MBI123456",
  "created_at": "2026-08-24T13:00:00Z"
}
```

### Admin Transactions

#### `GET /api/payments/transactions/`

List all transactions (admin only).

#### `GET /api/payments/transactions/{id}/`

Retrieve specific transaction (admin only).

## Admin Panel

Donation types and transactions can be managed via the Django admin panel:

```
/admin/
```

- **Donation Types**: List, create, edit donation categories
- **Transactions**: View all M-Pesa payments with status, receipt numbers, and timestamps
